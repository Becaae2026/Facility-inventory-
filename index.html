Bulk update from Excel

Paste from the downloaded template as-is — code, name and quantity — or just two columns, code and quantity. The quantity is taken from the last number on each line. Header rows are ignored. A CSV file works too.

Close the period

Takes today's closing balance and writes it in as the new opening figure for all 107 items. The two logs are copied to dated archive tabs, then emptied so the new period starts clean. A full backup runs first, automatically.

Clear all opening figures

Sets every opening figure to zero. Receipts and issues are left alone, so balances become movement-only. Use this when you're about to load a fresh physical count. A backup runs first.
